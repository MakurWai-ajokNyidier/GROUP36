# Team Charter — Group 36

## Operating Rules

| Rule | Description |
|---|---|
| **Communication** | All daily communications and async updates will occur in our dedicated WhatsApp group and Google Meet. |
| **Deadlines** | Board status moves must happen on the same day the work is performed. Batched end-of-week updates are strictly prohibited. |
| **Commit Convention** | All code and document edits must strictly follow the format: `<type>: <what changed> - <why it matters>`. Messages like `wip` or `updates` are invalid. |
| **Escalation Path** | If any team member shows zero visible activity for 2+ days, it triggers an immediate escalation to the project facilitator, rather than waiting for the deadline. |
| **Task Constraints (Anti-black-box Rule)** | No single task on the board will exceed 4 hours of work. If a task is larger, it must be split until the Definition of Done is a single checkable sentence. |
| **Conflict Resolution** | Disagreements are resolved via open discussion in the group chat first. If unresolved within 24 hours, the project facilitator mediates. No silent resentment. |
