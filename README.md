# 🌟 Northstar Retail Co. — Support Deflection MVP

**Group 36 | Power Learn Project | The Northstar Sprint**

A 1-week industry simulation to reduce manual ticket handling for Northstar Retail Co.'s support team. This MVP covers **Order Status** and **Returns & Refunds** inquiries via a chatbot interface.

## 🎯 What This MVP Does

| Ticket Type | Status | How It Works |
|---|---|---|
| **Order Status** | ✅ Live | User provides Order ID → bot returns status, tracking, and estimated delivery |
| **Returns & Refunds** | ✅ Live | User provides Return ID → bot returns refund status, amount, and timeline |
| **Stock Availability** | 🔄 Partial | User searches product → bot returns stock count and restock date |
